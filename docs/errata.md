# 更正记录

本页区分证据数值、对数值的解释，以及历史工具缺陷。历史原件私下保留；公开的是明确选择的摘要，不以脱敏后的文件哈希冒充历史原件哈希。

## 我们自己的错误

1. **误认像素摘要。** 曾因摘要前四个十六进制字符相同，把有效像素 SHA-256 误认为空数据摘要。实际像素摘要为 `e3b0bf6dd2fc4c85f88f0f50e30f690c59202297b4f3a90a02d687b3259b6a3a`；空摘要为 `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`，完整不等。原数字回执本就记录 `sha256_equals_empty_digest=false`。旧“hash anomalous”解释已撤回，不能拿它指控数据造假。
2. **用当前哈希充当预期值。** 早期文件身份辅助字段和一次生命周期 producer 字段将当前哈希与自身比较。该布尔值没有独立验证价值。公开摘要不导出它；文件哈希、输入固定身份和实际内容比较分别说明。
3. **复制驱动的 fixture 路径错误。** 导致早期运行退出；修正后换目录重新执行，没有把失败组作为成功对照。
4. **退出码的便携性。** 命令工具当时返回的退出码不在历史 result.json 的字段中。公开摘要只直接陈述回执能证明的 error/stopped 状态；不把无该字段的 JSON 当退出码原始证据。
5. **assert 验证门控失效。** 旧私有构建器与独立验证器使用 assert，Python `-O` 会关闭这些检查。发布复核实际构造了额外修改 MAIN 第0字节的无效候选：差异扩大到22字节、8个指令窗口，旧验证器在 `-O` 下仍打印 PASS 并以0退出。无效文件 SHA-256 为 `c4a59af73799abf360745e2d17bcdf9e66848de84459f3278ad41000a768c296`；旧验证器 SHA-256 为 `e186ba8b664b65b9aedfe63d0c0554646e1fca1b5401f5a38c899458e5d1e464`。公开静态构建器与验证器改用明确条件和异常，已在普通与 `-O` 模式拒绝同一坏样本；正确候选的完整身份与七处指令另行复核通过。测试见 [static-tests.json](../evidence/static-tests.json)。
6. **查询编号省略进制。** 本草稿早期表格曾写 `MOVZ W0,#23`；正确立即数是十六进制 `0x23`（十进制35），原值为 `0x24`。代码及原有候选使用正确值；已修正文档，避免把编号误读成十进制23。
7. **把替代分支当成成功反例。** 本草稿曾以 `bank8[999]` 的0值模板和非1分支推断1不是 RAW 的必要条件。静态存在分支不能证明该分支实际成功出片；现改为“尚不能认定其为通用必要条件”，保留运行验证未完成的状态。
8. **模型源码核对不完整。** 旧核对只覆盖 Nikon overlay 与部分集成文件，漏列 `system/physmem.c`、`accel/tcg/cputlb.c` 的观察修改。本轮比较官方 QEMU 包内全部78,691个普通文件，找到这两处额外修改，已纳入公开补丁及源码锁。旧“overlay一致”不能解释为完整源码已核对。
9. **观察地址注释错误。** 旧 hook 注释把 `ra` 写作 AArch64 guest PC，实际是 TCG helper 的宿主返回地址；未经独立转换不能用于固件 PC 证据。为重建源码身份，补丁保留原注释，并在 [MODEL.md](../runtime/MODEL.md) 明确纠正。
10. **局部补丁测试没有覆盖完整解压。** 新准备器第一次完整执行在 QEMU 源码包的绝对符号链接处失败。该链接是 EDK2 的 XCODE/macOS 包含桥，目标 `/opt/X11/include`，不是测试输入。修正后对全部72个链接核对身份与引用图，仅明确省略这一条，另外71条检查后创建。首次失败目录保留；随后换目录完成完整准备与编译。局部补丁应用成功不能冒充全流程成功。
11. **运行入口的验收不足。** 审查初稿时发现仅检查 MCU 入队、仅记录忙掩码，以及墙钟到期未必报错等缺口。现要求实际接收缓冲区与五步手势逐字节对应、手势前两份忙掩码全零、全部交付后完成规定虚拟等待；另核对 producer 快照地址/长度/身份。相关错误样本测试与实际三组执行分别记载，不用宿主测试代替固件运行。运行入口明确拒绝 `-O`，因为锁定的上游依赖仍使用断言。

## 输入资料的提取错误

一批旧模块文件存在提前32字节截取或前后模块污染；本次重新取片比对覆盖 EX、TPJ、EG、VR、LI 五份。LI 文件的前32字节来自前一模块尾，后16字节来自包尾，不是合法模块包装。路线4使用的 MAIN 已与正确 EG 切片去 CRC 后逐字节相等。这是物料审计发现，不能推广成原厂固件损坏。

## 交付状态的时间差

早期交接称没有安装容器；后续本地曾构造离线研究外包，但它从未通过相机准入、加载或恢复验证。准确现状是没有经相机验证的可安装交付。该研究外包不随本草稿分发，公开静态工具也不生成它。

## 表述限制

- 不称“Z8 RAW预拍固件已经完成”：当前验证的是固定模型中的首次半按触发原生 NEF。
- 不称“第二次 producer 完成就有第二张照片”：历史两周期实验每组仅一份 NEF。
- 不称“没人成功修改过 Z8”：上游 ProRes 项目有作者的真机验证声明；本候选的实机证据仍缺失。
- 不称“没有发现额外调用就是不存在”：间接引用、其他模式和时序未穷尽。
